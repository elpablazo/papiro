Papiro

The self-hosted Paperless alternative
that's 182× lighter.

Scan it, drop it, find it in a millisecond. An open-source document archive with OCR and instant full-text search, in one container that idles at 5 MB of RAM.

Same job. A fraction of the machine.

Paperless-ngx boots Django five times over and keeps Redis, PostgreSQL, Tika and Gotenberg running next to it. Papiro is one Rust process with SQLite inside. Measured on the same machine with the same documents.

Coming from Paperless?

Bring everything over in two commands: documents, OCR text (no re-OCR), tags, correspondents, types, notes, custom fields. Storage paths become folders. Every file is checked against its SHA-256.

# 1. In Paperless (read-only export)
docker compose exec webserver document_exporter ../export

# 2. In Papiro
docker compose run --rm -v /path/to/export:/import:ro \
  papiro import /import

Where Paperless still wins

  • PDF/A output, page cleaning and deskewing before OCR
  • Workflows, mail rules and group permissions
  • A trained classifier, 37 UI languages (Papiro has 2)
  • Years in production and a big community

If you need those, Paperless is great. If you want something light, fast and easy to trust, try Papiro.

Questions

Is it really free?

Yes. MIT-licensed, no paid tier, no telemetry, no account. You run it on your own machine.

Where do my documents live?

On your server: one SQLite database and your original files in a folder. papiro export writes them out with readable names, so you never depend on Papiro to read your archive.

Will it run on a Raspberry Pi?

Images are published for amd64 and arm64. It idles at a few MB of RAM, so small boards and cheap VPSs are fine; OCR speed depends on the CPU.

Does the auto-filing send my documents anywhere?

No. Suggestions come from rules and from similar documents you already filed, computed on your server. An optional LLM integration exists, but it's off unless you add an API key.

Which languages does the OCR read?

Anything Tesseract supports. The image ships with English and Spanish; add more with one build argument.
